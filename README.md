# Probably Stolen - Chem Calculator

Интерактивный калькулятор для игры **Probably Stolen**. Помогает рассчитать точные пропорции ингредиентов, учесть потери от модулей, рассчитать чистоту и прибыль, а также подготовить партию для сдачи Картелю.

## 🚀 Как использовать

Просто откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge). Калькулятор работает локально и не требует подключения к интернету.

## 🛠 Возможности

- **Все рецепты:** Пыль снов, Пыль кошмаров, Таблетка кофеина, Таблетка Фенты, Инъектор Оксинета.
- **Учет модулей:** Потери в блендере, точность нагрева термоплиты, загрязнение от упаковщика.
- **Точность:** Расчет необходимого алкоголя (70% или 100%), расчет мерных колб (100, 50 и 25 мл), пипеток (5 и 1 мл) и пилюль финишера (Зианид 0.6, Фента 0.5, Противозач. 0.1).
- **Порции варок:** Для рецептов с алкоголем добавляйте строки с ингредиентами на одну варку и количеством повторений. Калькулятор суммирует строки для общего выхода и показывает два сценария расхода алкоголя: весь объём для одной большой варки либо объём наибольшей порции, если варить последовательно и повторно использовать одну заливку. Для Пыли снов и Пыли кошмаров берётся 5× объёма пасты, для кофеина — 0,75× объёма кофейной пасты; коэффициенты применяются к пасте после потерь блендера. При 70%-м алкоголе объём корректируется по крепости; чистый алкоголь 100% берётся без поправки. Алкоголь округляется вверх до целого миллилитра и показывается в колбах (100, 50, 25 мл) и пипетках (5, 1 мл).
- **Кофеин из зёрен:** Учитывайте отдельно известный объём кофеина, уже содержащегося в зёрнах; он добавляется к расчётным 75% кофеинового экстракта из пасты.
- **Экономика:** Детальный расчет выручки с учетом качества, уровня контрабанды, сложности и скидок.
- **Картель:** Расчёт недельной квоты (рост на 5 флаконов за неделю, целевая чистота ограничена 70%), разбавки, доступного количества сдаваемого продукта и репутации по чистоте и числу флаконов.
